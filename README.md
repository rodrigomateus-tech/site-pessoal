## Sobre o Projeto

Site desenvolvido do zero como projeto pessoal antes do início da graduação em Sistemas de Informação. O objetivo desta *Landing Page* é apresentar os serviços de automação residencial, suporte de TI e consultoria em IA da RM Tech Solutions, focando em conversão de clientes via WhatsApp e design responsivo.

## Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

* **HTML5:** Semântica e estrutura.
* **Tailwind CSS:** Estilização utilitária e responsividade nativa (via CDN).
* **JavaScript (Vanilla):** Lógica para menu mobile, navbar com efeito *sticky* e acordeão de FAQ.
* **Lucide Icons:** Ícones minimalistas e modernos.

## Funcionalidades

* **Design Responsivo:** Totalmente adaptado para celulares, tablets e desktops.
* **Dark Theme Nativo:** Interface moderna baseada em cores escuras (Slate/Indigo).
* **Navegação Fluida:** *Smooth scroll* para as seções da página.
* **Integração Direta:** Botões de CTA (Call to Action) com links parametrizados para o WhatsApp.
* **Componentes Dinâmicos:** FAQ interativo e menu mobile otimizado.
